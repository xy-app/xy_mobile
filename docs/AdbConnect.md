# 网络调试连接 (Adb Connect) (AdbConnect)

通过网络 IP 地址和端口远程连接安卓手机或模拟器

## 运行参数

* **网络地址与端口 (`address`)**
  * 类型: `string`
  * 默认值: `"127.0.0.1:16384"`
  * 描述: 目标 IP:Port 组合字符串（如 '127.0.0.1:16384'）。常用预设：`127.0.0.1:16384 (MuMu 12 默认)`, `127.0.0.1:16416 (MuMu 12 多开2)`, `127.0.0.1:5555 (雷电/蓝叠 默认)`, `127.0.0.1:62001 (夜神 默认)`, `127.0.0.1:21503 (逍遥 默认)`, `127.0.0.1:7555 (MuMu 6 默认)`。

## 输出

* 类型: `string`
* 描述: 网络调试连接建立结果回执。

## 使用示例

```json
{
    "tag":  "AdbConnect",
    "address":  "127.0.0.1:16384"
}
```
