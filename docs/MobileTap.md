# 屏幕点击 (Mobile Tap) (MobileTap)

在手机或模拟器屏幕的指定位置模拟手指点击或双击

## 运行参数

* **目标设备 (Device Serial) (`device`)**
  * 类型: `string`
  * 默认值: `"auto"`
  * 描述: 目标设备唯一标识或模拟器 ADB 端口。填写 'auto' 将自动选择首个在线活跃设备；iOS 可填写 'booted' 匹配当前运行中的模拟器。常用预设：`auto`, `127.0.0.1:16384 (MuMu)`, `127.0.0.1:5555 (雷电)`, `emulator-5554 (AVD)`, `booted (iOS)`。
* **点击坐标 (X, Y) (`xy`)**
  * 类型: `string`
  * 默认值: `"500, 500"`
  * 描述: 触摸屏幕的像素绝对坐标，格式为 'X, Y'（如 '540, 960'）。常用预设：`500, 500`, `100, 200`, `540, 960`, `300, 600`。
* **点击次数 (`count`)**
  * 类型: `number`
  * 默认值: `1`
  * 描述: 连续点击次数，默认为 1（单击），设置为 2 时执行双击。常用预设：`1`, `2`。

## 输出

* 类型: `string`
* 描述: 触控操作执行状态结果。

## 使用示例

```json
{
    "tag":  "MobileTap",
    "device":  "auto",
    "xy":  "500, 500",
    "count":  1
}
```
