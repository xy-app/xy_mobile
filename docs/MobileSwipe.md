# 滑动与拖拽 (Mobile Swipe) (MobileSwipe)

在手机屏幕上模拟手指向上、下、左、右滑动翻页或长按拖拽

## 运行参数

* **目标设备 (`device`)**
  * 类型: `string`
  * 默认值: `"auto"`
  * 描述: 目标设备序列号或模拟器端口。常用预设：`auto`, `127.0.0.1:16384`, `booted`。
* **起始坐标 (X1, Y1) (`from_xy`)**
  * 类型: `string`
  * 默认值: `"500, 800"`
  * 描述: 滑动起始点像素坐标，格式为 'X, Y'。常用预设：`500, 800 (上滑起点)`, `500, 200 (下滑起点)`, `800, 500 (左滑起点)`。
* **终止坐标 (X2, Y2) (`to_xy`)**
  * 类型: `string`
  * 默认值: `"500, 200"`
  * 描述: 滑动终点像素坐标，格式为 'X, Y'。常用预设：`500, 200 (上滑终点)`, `500, 800 (下滑终点)`, `200, 500 (左滑终点)`。
* **滑动耗时 (毫秒) (`duration_ms`)**
  * 类型: `number`
  * 默认值: `300`
  * 描述: 从起点移动到终点所经历的手势持续时间（毫秒），耗时越长越接近慢速拖拽。常用预设：`200`, `300`, `500`, `1000`。

## 输出

* 类型: `string`
* 描述: 手势滑动执行状态结果。

## 使用示例

```json
{
    "tag":  "MobileSwipe",
    "device":  "auto",
    "from_xy":  "500, 800",
    "to_xy":  "500, 200",
    "duration_ms":  300
}
```
